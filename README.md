## Structure
- `notes/` : condensed theory in my own words
- `exercises/` : worked solutions with proofs and edge cases
- `exams/` : past papers and attempts
- `figures/` : SVG diagrams
- `templates/` : templates to copy for new notes or exercises

## Conventions
- Math in LaTeX: `$inline$` and `$$display$$`
- Diagrams as SVG in `figures/`, committed as text
- One commit per exercise, messages prefixed: `ex:`, `notes:`, `fix:`
